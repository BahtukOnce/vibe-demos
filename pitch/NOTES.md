# Персональные демо для лидов: решения и заметки

Рабочий журнал. Обновляется по ходу работы.

## Где что лежит

- `pitch/<slug-хвост>/index.html` — одно демо = один файл: HTML, CSS и JS внутри, без фреймворков.
- `pitch/index.html` — пустая страница с редиректом на витрину. Списка компаний нет.
- `robots.txt` в корне — `Disallow: /pitch/`.
- `pitch/_tools/` — генератор (`build.mjs`, `kit.mjs`, `sites/*.mjs`) и проверка `check.mjs`.
  Папки с `_` Jekyll на GitHub Pages не публикует.
- `pitch/_screens/` и `pitch/_outreach.md` — в `.gitignore`, в репозиторий не попадают.

## Решения

- **Отдельный репозиторий `pitch-demos` не создаём** (решение владельца). Демо лежат в `vibe-demos/pitch/`.
  На витрину (корневой `index.html`) не добавляются.
- **Имена папок**: slug + 4 случайных символа (`secrets`), чтобы демо нельзя было перебрать по ссылке.
  Важно: репозиторий публичный, поэтому сами папки видны на github.com. Хвост защищает только от перебора
  адресов на Pages, но не от просмотра дерева репозитория.
- **robots.txt**: у сайта проекта (`bahtukonce.github.io/vibe-demos/`) поисковики читают robots.txt
  только из корня домена `bahtukonce.github.io`, а не из `/vibe-demos/`. Поэтому основная защита от
  индексации — `<meta name="robots" content="noindex, nofollow">` в каждом демо (есть везде).
- **Генератор вместо 15 копий вручную**: общий «скелет» (плашка-концепт, липкая панель, прайс, рейтинг,
  маршрут, контакты, формы-заглушки) написан один раз, чтобы не было 15 разных багов. Дизайн, палитра,
  шрифты, первый экран и ключевая фишка у каждого демо свои. На выходе — обычный статичный `index.html`,
  его можно править руками.
- **Фото** с их страниц не используются. Визуал — SVG/CSS, места под фото — плейсхолдеры
  «Здесь будут ваши фото работ».
- **Отзывы** не копируются. Только рейтинг и число отзывов со ссылкой на карточку в Яндекс Картах.
- **Формы** ничего не отправляют: показывают «Это демо: заявка не отправлена». Где у компании есть
  реальная онлайн-запись (YCLIENTS, DIKIDI), кнопки «Записаться» ведут на неё.
- **Карта** — нарисованная SVG-«схема» со ссылкой на карточку в Яндекс Картах, без встраивания чужих
  скриптов (быстрее, без cookie и без ошибок в консоли).
